A two-line robot apology for make.fun's "The Robot Apology" bounty ($2, winner takes all). Line one owns one specific mistake — the robot washed a white shirt with the red socks and turned it pink. Line two says what it learned and what it will do differently: sort the laundry by colour and check every item against the load before pressing start. The lesson follows from the exact mistake, and the voice is a machine noticing its own slip.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the two lines to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
